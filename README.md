# Urban Yuva Ecommerce Website

Urban Yuva is a mobile-first men's streetwear store built for Indian college students. It uses only plain HTML, CSS and JavaScript, so there is no framework, package installation or build step.

## Main Features

- Responsive mobile-first design
- Product catalogue with category filters and search
- Dynamic product pages using URL parameters
- Wishlist saved in the browser
- Shopping cart with quantity updates and removal
- Cart data saved with `localStorage`
- Coupon code support (`CAMPUS10`)
- UPI and Cash on Delivery checkout options
- WhatsApp order and contact forms
- Size guide, FAQ, shipping, returns and order tracking pages
- SEO titles, descriptions and Open Graph sharing tags

## Preview the Website

Open `index.html` in any modern browser. No server or installation is required.

## Important Files

- `index.html` — home page
- `shop.html` — complete product catalogue
- `product.html` — dynamic product details
- `cart.html` — shopping cart
- `checkout.html` — delivery and payment form
- `css/style.css` — all website styling
- `js/products.js` — product names, prices, sizes and images
- `js/main.js` — cart, wishlist, checkout and other interactions
- `images/` — product and brand images
- `PROJECT_BRIEF.md` — original project requirements

## Customise Before Launch

1. Replace the placeholder products and photos in `js/products.js` and `images/`.
2. Replace the WhatsApp number and UPI ID near the top of `js/main.js`.
3. Replace the placeholder email address throughout the website.
4. Replace `https://your-domain.com` in the Open Graph image tags after choosing a domain.
5. Replace the placeholder UPI QR code in `images/upi-qr-placeholder.svg`.
6. Review the sample sizes, shipping details and return policy before publishing.

## Deployment

Because this is a static website, it can be hosted on GitHub Pages, Netlify, Cloudflare Pages or another static hosting service.

## Technology

- HTML5
- CSS3
